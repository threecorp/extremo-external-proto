BookingEvent

BookingEvent is one entry in a tenant's booking change feed: an append-only,

cursor-paginated stream of booking lifecycle changes. An external consumer

polls "what changed since my last cursor", and the same feed backs webhook

delivery. Internal audit detail (actor identity, raw field diffs) is not

exposed.

FieldTypeLabelDescription

Opaque cursor for this event. Pass the response's next_cursor back as the request cursor to fetch events after this one.

What kind of change this event represents.

booking_id uint64

Opaque public identifier of the booking this event is about.

occurred_at google.protobuf.Timestamp

When the change occurred (UTC).

booking Booking

Snapshot of the booking after the change. Absent if the booking has since been hard-deleted (the event type still records what happened).

ListSlotsRequest

ListSlotsRequest selects a tenant + services + date range to compute availability for.

FieldTypeLabelDescription
tenant_id uint64

Tenant whose availability to compute.

service_id uint64

A single service whose total duration (children included) drives slot feasibility. Set this or service_ids, not both.

opened_at google.protobuf.Timestamp

Start of the date range to compute (inclusive).

closed_at google.protobuf.Timestamp

End of the date range to compute (exclusive).

service_ids uint64 repeated

Services booked together (the service_ids CreateBooking will receive). A slot is available when the sum of their total durations fits from its start, as CreateBooking checks. Set this or service_id, not both.

consumer_id uint64

Optional consumer the booking is for (Consumer.id). When set, slots that would overlap one of this consumer's own live bookings are FULL, because CreateBooking / UpdateBooking reject a consumer's double booking. A consumer that cannot book (pending or deactivated) is INVALID_ARGUMENT.

exclude_booking_id uint64

Optional booking being rescheduled (Booking.id). When set, that booking is not counted, as UpdateBooking does not count it against itself, and the slots are checked for the staff and consumers it keeps, as UpdateBooking checks them.

ListSlotsResponse

ListSlotsResponse is the computed availability grid for the requested range.

FieldTypeLabelDescription
slots extremo.msg.external.v1.AvailabilitySlot repeated

Per-slot availability over the requested range.

schedule_type string

Scheduling strategy used to compute the grid: "coop", "slot", or "hybrid".

AvailabilityService

authenticated external API consumers. Read-only.

Method NameRequest TypeResponse TypeDescription
ListSlots ListSlotsRequest ListSlotsResponse

ListSlots returns per-slot availability (AVAILABLE / BUSY / FULL) for a tenant's service, or several services booked together, over a date range.

CreateBookingRequest

CreateBookingRequest books one or more services for a consumer at a start

time. The end time is derived server-side from the services' total duration,

so no end time is accepted.

The consumer must already exist: register one through ConsumerService, keep

the returned Consumer.id, and pass it here. Booking never creates a consumer

as a side effect. A partner holding its own id instead of ours can translate

it with ConsumerService.ListConsumers (external_id filter).

BookService

BookService exposes a tenant's bookings to authenticated external API

consumers: reads (book.read) plus create / update / status changes

(book.create, book.update). The status changes behave as in the admin UI.

Method NameRequest TypeResponse TypeDescription
ListBookings ListBookingsRequest ListBookingsResponse

ListBookings returns a tenant's bookings overlapping [start_at, end_at), newest first, paginated: a booking crossing either edge of the window is included, one that only touches it is not (a zero-length booking at start_at is included). A window with end_at not after start_at lists nothing. Requires book.read.
GetBooking GetBookingRequest GetBookingResponse

GetBooking returns a single booking by its opaque id, scoped to the tenant. Requires book.read.
CreateBooking CreateBookingRequest CreateBookingResponse

CreateBooking books a service for a registered consumer (consumer_id), validates the slot against the tenant's schedule (capacity / staff / no past times), sends the same notifications as an in-store booking, and returns the new booking (DRAFT, or RESERVED when the tenant auto-accepts). Requires book.create. Supply idempotency_key to make retries safe: resending the same key replays the original booking instead of creating a duplicate.
UpdateBooking UpdateBookingRequest UpdateBookingResponse

UpdateBooking changes a booking's time / services / name / desc, and its external_id / metadata. Requires book.update. Pass expected_updated_at (from Booking.updated_at) for optimistic concurrency; a mismatch returns ABORTED. Changing only external_id / metadata leaves the booking itself untouched.
CancelBooking CancelBookingRequest CancelBookingResponse

CancelBooking cancels a booking (DRAFT / RESERVED / ORDERED -> CANCELED). Requires book.update. There is no hard-delete on the external surface.
AcceptBooking AcceptBookingRequest AcceptBookingResponse

AcceptBooking confirms a DRAFT booking (DRAFT -> RESERVED), as the admin UI does. Requires book.update.
RejectBooking RejectBookingRequest RejectBookingResponse

RejectBooking declines a DRAFT booking (DRAFT -> CANCELED) of a tenant that does not auto-accept, as the admin UI does. Requires book.update.
NoShowBooking NoShowBookingRequest NoShowBookingResponse

NoShowBooking records that the consumer did not show up (RESERVED -> NO_SHOW), as the admin UI does. Requires book.update.

ConsumerService

ConsumerService manages a tenant's consumers (CONSUMER records) over the external

partner API. Reads require the consumer.read scope; writes require consumer.write.

Method NameRequest TypeResponse TypeDescription
CreateConsumer CreateConsumerRequest CreateConsumerResponse

CreateConsumer registers a tenant consumer; it creates no sign-in for them. One contact identifies the consumer and is the only one stored: with both, the email identifies them and the phone is not stored (keep it in metadata if you need it). Registering a contact that is already a consumer of this tenant returns that consumer; a consumer removed with DeleteConsumer is restored. Rejected with AlreadyExists if the contact belongs to tenant staff (OWNER/MEMBER), to a person registered only at another tenant, or to a deleted account whose email or phone it is, or if external_id is used by another consumer. A registration racing another one for the same person fails with AlreadyExists or, on a deadlock, Aborted; retry the call.
GetConsumer GetConsumerRequest GetConsumerResponse

GetConsumer returns a consumer by its Extremo id.
ListConsumers ListConsumersRequest ListConsumersResponse

ListConsumers returns the tenant's consumers, paginated. Filter by external_id to look a consumer up by the partner's own id.
UpdateConsumer UpdateConsumerRequest UpdateConsumerResponse

UpdateConsumer updates a consumer's mutable fields (display name, external_id, metadata).
DeleteConsumer DeleteConsumerRequest DeleteConsumerResponse

DeleteConsumer deactivates the consumer's CONSUMER role for this tenant (soft; the underlying global user is never deleted). CreateConsumer with the same contact restores the consumer.
